# AI Website Builder Dashboard

This project is a browser-based website generator dashboard built with HTML, CSS, and JavaScript. It lets you:

- Select from 24 professional website layouts
- Enter standard customer business data
- Generate a polished website draft instantly in the browser
- Preview the generated site in an iframe
- Copy or download the resulting HTML file

## Files
- `ai-website-builder-dashboard.html` — main app entry point
- `assets/style.css` — dashboard styles
- `assets/app.js` — generator logic, preview, theme toggle, export tools
- `templates-data/catalog.json` — template library metadata
